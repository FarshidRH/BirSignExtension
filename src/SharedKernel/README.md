Shared Kernel for BirSign

## Supported frameworks

Targets .NET Standard 2.0, so it can be used from:

- .NET Framework 4.6.1 and later (4.7.2 or later recommended)
- .NET Core 2.0, .NET 5 and later

This package holds the DTOs, constants and helpers shared by the
`MapIdeaHub.BirSign.NetCoreExtension` and `MapIdeaHub.BirSign.NetFrameworkExtension` packages.
